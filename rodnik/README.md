# Родник

Рукописная книга стихов Валентина Лаврищева. Самостоятельная статическая подстраница для `https://vivoxti.github.io/rodnik/`: HTML, CSS, JavaScript и локальные изображения/шрифт. Сборщик сайта и внешние сервисы не нужны.

## Просмотр

Из корня репозитория запустите локальный HTTP-сервер, например `python -m http.server 8034`, и откройте `http://localhost:8034/rodnik/`. Открытие HTML напрямую через `file://` не поддерживается: браузер блокирует загрузку JSON.

## Обновление книги

Сначала подготовьте и проверьте новые PNG с прозрачным почерком и TXT в `BookGrandpa` сохранёнными там инструментами. Затем из корня репозитория:

```powershell
& 'C:\Users\Dmytr\Desktop\BookGrandpa\_Инструменты\venv\Scripts\python.exe' '.\rodnik\tools\build_book.py' --source 'C:\Users\Dmytr\Desktop\BookGrandpa'
```

Нужны Pillow, NumPy и OpenCV (уже установлены в окружении книги). Скрипт читает исходные файлы, но не меняет их. Он обновляет `assets/book.json`, прозрачные WebP без потери качества и изображение обложки. Почерк не перерисовывается: основной текст и рукописные номера разделены на отдельные картинки. Проверка восстанавливает исходный PNG из этих частей и сравнивает все видимые пиксели и альфа-канал.

Масштаб задаётся размером клетки на фотографии, а положение текста — координатами на исходном листе. Общая модель листа содержит 28 × 42 клетки. Рукописные номера размещаются по центру на одной нижней линии. Расшифровки используют один размер шрифта на всех листах со стихами, сохраняя исходные переводы строк и приблизительное положение коротких стихов. Стихи набраны шрифтом Pangolin (он шире и ближе к рукописному, чем Neucha) с лёгким контуром 0,015 em и межстрочным интервалом 1,2. Размер — наибольший, при котором самый высокий стих помещается на лист целиком без прокрутки; он пересчитывается для каждого размера листа. Несколько самых длинных строк (около 0,6 % всех) переносятся на следующую строку с отступом, остальные остаются целыми. Текстовое содержание использует отдельные строки с точечными линиями и ссылками на стихотворения.

Разметка сохранена в `tools/page_layout.json`. При добавлении новой страницы сначала измерьте её и просмотрите номер в `numbers-1.jpg` рядом с оригиналом:

```powershell
& 'C:\Users\Dmytr\Desktop\BookGrandpa\_Инструменты\venv\Scripts\python.exe' '.\rodnik\tools\calibrate_book.py' --source 'C:\Users\Dmytr\Desktop\BookGrandpa' --review 'C:\Users\Dmytr\Desktop\BookGrandpa\_Инструменты\Сайт_Родник\Разметка_новых' --files 086
```

Перенесите запись новой страницы из `calibration.json` в `tools/page_layout.json`, проверьте `grid` (шаг клетки по двум осям) и `numberBox` (область номера от 0 до 1000), затем отметьте `reviewed: true`. Сборщик требует проверенную разметку. После сборки запустите `tools/check_book.py --source ...` и `tools/review_layout.py --output ...`: первый проверит отсутствие повторных номеров, обрезки и изменения штрихов, второй сохранит обзор всех листов в едином масштабе.

Страницы 3–164 идут в исходном порядке. Пропуски 86, 140 и 163 показаны как оставленные места и автоматически заменяются, когда появятся соответствующие файлы. Страницы 1 и 2 не добавляются. Содержание для навигации извлекается из пяти проверенных текстовых листов содержания; оригиналы этих листов также включены в книгу.

## Возможности

Для текстовых листов содержания подбирается наибольший размер, при котором помещается каждый лист, и этот самый маленький из подходящих размеров применяется ко всем пяти листам. При добавлении новых записей подгонка сохраняется автоматически.

- Передняя обложка из семейного архива и оформленная задняя с именем автора.
- Объёмная книга, плавное парение, открытие и перелистывание с двухсторонним листом. Закрытая книга слегка поворачивается вслед за мышью или наклоном телефона (на iOS — после разрешения доступа к движению при первом касании). Закладка — цельная лента с мягким покачиванием.
- Книга собрана из двух половин, которые поворачиваются вокруг корешка: при открытии передняя половина раскрывается вместе с первой страницей, а сама книга плавно переезжает в центр. После последнего листа задняя половина закрывается поверх и показывает заднюю обложку, без дополнительной страницы «Конец»; обратная прокрутка раскрывает её назад, к последнему развороту. Колесо открывает и закрывает книгу только в естественную сторону: вперёд — с передней обложки, назад — с задней.
- Разворот на широком экране и одна страница на телефоне; свайпы, стрелки клавиатуры и колесо мыши. Колесо открывает переднюю обложку и возвращает с задней к последнему листу. Над длинной расшифровкой колесо сначала прокручивает текст; над краем книги перелистывает. Один жест не запускает цепочку переворотов.
- Оригинальный почерк и расшифровка шрифтом Neucha. Шрифт — приблизительное сходство с рукописными печатными буквами; оригинальный режим сохраняет настоящий почерк.
- Увеличение отдельной кнопкой лупы (нажатие на лист его не увеличивает), поиск по названиям и всему тексту, переход по номеру, сохранение места чтения на устройстве.
- Прямые ссылки вида `#page=029`, поддержка уменьшенного движения, доступные названия элементов.
- Изображения следующих страниц подгружаются по мере чтения.

Шрифты хранятся локально вместе с лицензиями SIL OFL: [Pangolin](https://github.com/google/fonts/tree/main/ofl/pangolin) для стихов в текстовом режиме, [Neucha](https://github.com/google/fonts/tree/main/ofl/neucha) для содержания и запасной вариант, [Russo One](https://github.com/google/fonts/tree/main/ofl/russoone) для крупного заголовка, похожего на надпись на обложке. Сайт не отправляет семейные материалы во внешние сервисы.

## Публикация

GitHub Pages репозитория использует ветку `master`, корневую папку. После публикации изменений подстраница доступна по `/rodnik/`. Другие разделы сайта не требуют изменений.
